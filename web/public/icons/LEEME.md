# Íconos de Age of Empires II

Los `.png` de esta carpeta son íconos de Age of Empires II: Definitive Edition (© Microsoft Corporation), sacados de una
instalación del juego con `tools/extractor/icons.py` y achicados a 64×64. **No son parte de la licencia MIT del
repositorio.**

Se usan bajo las [Game Content Usage Rules](https://www.xbox.com/en-US/developers/rules) de Microsoft: AoE2 BO Coach es
gratis y sin fines comerciales, y la web muestra el aviso que piden las reglas. Microsoft puede retirar ese permiso; si
pasa, se borra esta carpeta y el editor muestra los nombres sin íconos.

Para rehacerlos (por ejemplo, con un parche que agrega unidades): `tools/extractor/.venv/Scripts/python.exe tools/extractor/icons.py`.
