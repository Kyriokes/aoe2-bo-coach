# Diseños y planes

Estado: de referencia. `specs/` tiene los diseños aprobados, con sus decisiones y maquetas. `plans/` tiene los planes de implementación paso a paso, **ya ejecutados**: las rutas y las clases que citan pueden haber cambiado o ya no estar (el editor WPF y `BuildOrderLibrary` se fueron en la v0.9.52; se recuperan con la etiqueta de git `editor-wpf`). Si un spec y el código no coinciden, manda el código, y lo que cambió después suele estar en `docs/dev/`.
